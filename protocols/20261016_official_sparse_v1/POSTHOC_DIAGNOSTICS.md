# Post-hoc mechanism diagnostics

Authorized by the user's request to analyze existing outputs. This is exploratory after seeing negative development/validation results, not a new prespecified confirmatory endpoint or parameter search.

Use the nine frozen development clips only for mechanism diagnostics. Pair full and uncertainty on identical frame/structure/density keys. Summarize AUC by procedure and structure, budget deltas, selected-query trajectories and adverse cases. Attribute differences descriptively; the original comparison changes error proxy, proximity and redundancy together, so it does not isolate proximity causally. Use the existing ablations to separate component contrasts.

Read saved initial predictions on CPU to measure predicted proximity, initial entropy and released-reference Dice at six annotated snapshots. Query gold is accessed only retrospectively for evaluation, never in an operational selector. Examine saturation, within-procedure descriptive rank correlation with baseline error, and first-decision changes. Reconstruct only first-decision scores; later propagated probability states were not retained and cannot be inferred from query logs. Saved baseline images are not post-propagation failure overlays.

Keep all final-test cases closed. Do not optimize on scoring gold or revise endpoint in response to results. No new annotations, model training or GPU inference is required. Sparse one-clip-per-source data cannot establish clinical benefit or a generalizable learned error predictor.
